# Gamealone

A desktop app where you play classic games against the computer. Everything runs offline.

## Tech stack

- **C++17**
- **SDL2** + **SDL2_ttf** for graphics and text
- **CMake** for building

## What it does

Opens with a home screen, then a library of eight games. Selecting a game shows the full rules first, then you start playing.

- Tic-Tac-Toe  
- Battleship  
- Connect Four  
- Checkers  
- Hangman  
- Memory Match  
- Rock Paper Scissors  
- Reversi  

Each game has Easy / Medium / Hard difficulty and dark/light theme.
